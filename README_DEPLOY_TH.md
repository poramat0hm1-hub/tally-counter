# วิธีเอาแอปนี้ขึ้นเว็บจริง (ฟรี) แล้วติดตั้งบนมือถือ

ไฟล์ในโฟลเดอร์นี้:
- `index.html` — หน้าเว็บหลักของแอป
- `manifest.json` — บอกเบราว์เซอร์ว่านี่คือแอปที่ติดตั้งได้ (ชื่อ, ไอคอน, สี)
- `service-worker.js` — ทำให้ใช้งานได้แม้ไม่มีเน็ต (offline)
- `icon-192.png`, `icon-512.png` — ไอคอนแอป

ทั้ง 5 ไฟล์นี้ **ต้องอยู่โฟลเดอร์เดียวกัน** ห้ามแยกที่ ห้ามเปลี่ยนชื่อไฟล์

---

## วิธี host ฟรีที่ง่ายที่สุด — GitHub Pages

1. สมัคร/ล็อกอิน **github.com**
2. กด **"New repository"** ตั้งชื่ออะไรก็ได้ เช่น `tally-counter` → เลือก **Public** → Create
3. ในหน้า repo กด **"Add file" → "Upload files"**
4. ลากไฟล์ทั้ง 5 ไฟล์ในโฟลเดอร์นี้ใส่เข้าไป → กด **Commit changes**
5. ไปที่ **Settings** (แท็บบนสุดของ repo) → เมนูซ้าย **Pages**
6. ตรง **Branch** เลือก `main` → โฟลเดอร์ `/ (root)` → กด **Save**
7. รอ 1-2 นาที จะได้ลิงก์ประมาณ:
   ```
   https://ชื่อบัญชีคุณ.github.io/tally-counter/
   ```

## ติดตั้งบนมือถือ

1. เปิดลิงก์ข้างบนด้วย **เบราว์เซอร์บนมือถือ** (Chrome บน Android, Safari บน iPhone)
2. **Android (Chrome):** จะมี popup หรือเมนู "⋮" → **"Add to Home screen" / "Install app"**
3. **iPhone (Safari):** กดปุ่ม **Share (ไอคอนสี่เหลี่ยมมีลูกศร)** → เลื่อนหา **"Add to Home Screen"**
4. ไอคอนแอปจะไปโผล่ที่หน้าจอโฮมเหมือนแอปทั่วไป เปิดแล้วเต็มจอ ไม่มีแถบเบราว์เซอร์

---

## ข้อควรรู้

- **Wake Lock (กันจอดับ), การสั่น, GPS** จะทำงานได้เต็มที่ก็ต่อเมื่อเปิดผ่านลิงก์ที่ host จริง (https) แบบนี้เท่านั้น — ใช้ในพรีวิวแชทไม่ได้เต็มรูปแบบ
- ข้อมูลที่นับ (localStorage) **ผูกกับเบราว์เซอร์/อุปกรณ์เครื่องนั้น** ยังไม่ sync ข้ามเครื่อง — ถ้าอยากให้หลายคนนับพร้อมกันแล้วรวมข้อมูลได้ ต้องเพิ่มระบบฐานข้อมูลออนไลน์ทีหลัง (เช่น Firebase ฟรี)
- ทุกครั้งที่แก้ไฟล์แล้วอยาก update แอปที่ติดตั้งไปแล้ว ให้กลับไป upload ไฟล์ใหม่ทับใน GitHub repo เดิม เดี๋ยว service worker จะอัปเดตให้เองรอบถัดไปที่เปิดแอป (มีเน็ต)
